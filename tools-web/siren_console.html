USB SERIAL · WEB SERIAL

Device connection

Use Chrome, Edge, or the VS Code Chromium browser. Press Connect to choose a USB serial device in the browser; no server or Python bridge is used. Close ESP-IDF Monitor and other serial apps first because the UART can only be opened by one app at a time.

Opening the serial port may reset the board. Firmware identity is verified before controls are enabled; playback never starts on connect.

Sound library

Presets are stored in this browser profile. Import/export transfers user presets as JSON; applying a preset updates the complete configuration and commits NVS once without starting playback.
