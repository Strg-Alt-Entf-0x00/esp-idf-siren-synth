    SIREN SYNTH STUDIO

    Hardware quick reference

    Connect and read the device

    Use the USB icon in the header to select the ESP32. The page verifies the firmware before enabling controls and reads the current playback, configuration, and audio status.

    Playback and volume

    Start uses the firmware safety timeout. Cancel requests a gradual wind-down; Brake stops quickly and can interrupt a wind-down. The header volume control stays inactive until a real device value has been read.

    Configuration and presets

    Signal, Room & effects, and Chopper & RPM settings are shown together on one page. Device values come from firmware. Saved presets stay in this browser; selecting one asks for confirmation before saving its settings to the device. Playback does not start.
